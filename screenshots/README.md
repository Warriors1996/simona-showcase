# Capturas pendientes

Sacá las capturas directamente de la app corriendo (`npm start` en la carpeta real del proyecto) y guardalas acá con estos nombres — el README principal ya las referencia:

- `01-dashboard.png` — Inicio / resumen ejecutivo
- `02-pos.png` — pantalla de venta (Ventas / Mesas)
- `03-kitchen.png` — kitchen display
- `04-stock.png` — Stock

Recomendaciones antes de subirlas:
- Usá datos de ejemplo, nunca ventas, clientes, montos o nombres reales del cliente.
- Recortá o difuminá cualquier dato sensible que quede visible (RUC/CUIT, teléfonos, direcciones).
- Formato PNG, ancho ~1280px está bien para que el README cargue rápido.
